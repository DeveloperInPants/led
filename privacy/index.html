2. Цель обработки

3. Какие данные обрабатываются

  • фамилия, имя и отчество;

4. Основание и действия с данными

Основанием обработки является согласие пользователя, выраженное установкой отметки в форме заявки. Оператор может получать, записывать, систематизировать, хранить, уточнять, использовать и удалять данные только в объёме, необходимом для указанных целей.

6. Права пользователя

Пользователь может запросить сведения об обработке своих данных, уточнить их, потребовать ограничить обработку или отозвать согласие. Для этого направьте обращение на email@example.ru. В обращении укажите сведения, которые позволят идентифицировать заявку.
