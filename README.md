# Ватэс — статическая версия для GitHub Pages

Это копия лендинга в HTML, CSS и JavaScript. Она предназначена только для визуального предпросмотра на GitHub Pages.

## Публикация

1. Создайте новый репозиторий GitHub и загрузите в него содержимое этой папки.
2. В репозитории откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/(root)`, затем сохраните настройки.
5. GitHub покажет публичную ссылку вида `https://ваш-логин.github.io/название-репозитория/`.

Файл `.nojekyll` оставлен намеренно: GitHub Pages должен отдать статические файлы без обработки Jekyll.

## Ограничение

GitHub Pages не выполняет PHP. Поэтому форма в этой копии проверяет поля в браузере, но не отправляет заявку и не использует почту. Для рабочей формы нужен исходный PHP-проект на хостинге с поддержкой PHP, например SprintHost.
